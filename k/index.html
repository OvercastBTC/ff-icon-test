STRATEGY K - apple-touch-icon as BASE64 data URI

apple-touch-icon (with sizes) whose href is an inline base64 data: URI PNG. Docs say Safari does NOT reliably accept data: URIs here - this is the empirical check.

Expected icon

PASS = crimson "K" tile. FAIL = monogram/fallback (confirms data: URIs do not work for apple-touch-icon).

Declaration under test

<link rel="apple-touch-icon" sizes="180x180" href="data:image/png;base64,iVBORw0KGgo...(inlined)">

Install test

  1. Open FF-K in the browser you are testing.
  2. Share -> Add to Home Screen -> Add.
  3. Record PASS (real K tile) / FAIL (monogram/fallback) per browser, and note the Add-dialog preview vs the installed tile.
