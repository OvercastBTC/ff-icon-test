STRATEGY J - rel="icon" as BASE64 data URI

A standard rel="icon" whose href is an inline base64 data: URI PNG - NO external file, NO apple-touch-icon, NO manifest. Tests whether an inlined icon can drive the Home-Screen tile (matters for BATTERY single-file build).

Expected icon

PASS = orange "J" tile. FAIL = monogram/fallback. Watch the installed tile, not just the share sheet.

Declaration under test

<link rel="icon" type="image/png" sizes="180x180" href="data:image/png;base64,iVBORw0KGgo...(inlined)"> <link rel="icon" type="image/png" sizes="512x512" href="data:image/png;base64,...">

Install test

  1. Open FF-J in the browser you are testing.
  2. Share -> Add to Home Screen -> Add.
  3. Record PASS (real J tile) / FAIL (monogram/fallback) per browser, and note the Add-dialog preview vs the installed tile.
