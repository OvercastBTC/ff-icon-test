Firefox iOS — Home-Screen Icon Test

Each page below isolates one icon-declaration strategy. Add each to your iPhone Home Screen from Firefox iOS, then check whether the installed icon matches the big coloured letter on the page. Record PASS / FAIL. Open these in Firefox on your iPhone (not Safari) for a valid test.

How to run each test

  1. Tap a strategy below to open its page.
  2. Firefox → hamburger/Share → Add to Home Screen → Add.
  3. Look at the new Home Screen icon. Matches the page's letter/colour = PASS. White box, screenshot, or globe = FAIL.
  4. Note the result for that letter, then come back and do the next.
